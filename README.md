# نظام إدارة فريق السوشال ميديا

تطبيق Next.js كامل لإدارة فريق السوشال ميديا — جدولة، أحمال عمل، خطط شهرية، وتقويم بثلاث طرق عرض (يومي، أسبوعي، شهري).

## المتطلبات

- Node.js 18+ (يفضل 20)
- npm أو yarn

## التثبيت السريع

```bash
# انتقلي إلى مجلد المشروع
cd sm-team-dashboard

# تشغيل كل خطوات الإعداد دفعة واحدة
npm run setup

# تشغيل التطبيق
npm run dev
```

افتحي [http://localhost:3000](http://localhost:3000) في المتصفح.

## التثبيت اليدوي (خطوة بخطوة)

```bash
# 1. تثبيت الحزم
npm install

# 2. توليد Prisma Client
npx prisma generate

# 3. إنشاء قاعدة البيانات وتطبيق الـ schema
npx prisma db push

# 4. زرع البيانات الأولية (5 موظفين + 6 شركات)
npm run db:seed

# 5. تشغيل التطبيق
npm run dev
```

## أوامر مفيدة

| الأمر | الوظيفة |
|-------|---------|
| `npm run dev` | تشغيل التطبيق في وضع التطوير |
| `npm run build` | بناء التطبيق للإنتاج |
| `npm run start` | تشغيل البناء النهائي |
| `npm run db:seed` | إعادة زرع البيانات الأولية |
| `npm run db:studio` | فتح Prisma Studio لإدارة البيانات بصرياً |
| `npm run db:push` | تحديث schema قاعدة البيانات |

## التقنيات

- **Next.js 14** (App Router) — الواجهة الأمامية والخلفية

- **Server Actions** — عمليات CRUD بدون REST API

## المميزات

### 1. تقويم بثلاث طرق عرض
- **يومي**: كرت لكل موظف يعرض مهامه ليوم محدد
- **أسبوعي**: شبكة (موظفين × 5 أيام عمل) — رؤية شاملة لمن يشتغل على ماذا
- **شهري**: تقويم تقليدي مع تجميع المهام حسب اليوم
- فلترة حسب الموظف والشركة في كل العروض

### 2. جدولة تلقائية ذكية
- الكاتبة تبدأ الخطط من 15 الشهر السابق
- بعد الموافقة (للشركات اللي بحاجة) → الإنتاج
- التصميم يحترم قاعدة "بوست أو ريل AI باليوم نفسه — مش الاثنين"
- Fallback تلقائي للقائد لو المصمم متشبّع
- العطلة: الخميس والجمعة

### 3. ترتيب أولويات بالسحب والإفلات
- اسحبي الشركات لإعادة الترتيب
- زر "إعادة جدولة فوراً" لإعادة توليد المهام حسب الترتيب الجديد

### 4. أحمال عمل مرئية
- نسبة استخدام شهرية لكل موظف
- تحذير عند تجاوز 100%
- تفصيل المهام حسب النوع

### 5. RTL كامل + تيمة عربية
- خط Tajawal للنصوص
- خط Reem Kufi للعناوين
- ألوان تيمة داكنة مع لمسات ذهبية
